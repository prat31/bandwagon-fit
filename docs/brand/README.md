# Brand

The logo is **rally rings** (option 2 in `logo-options/`): three friends' arcs in the brand green,
orange and blue close one loop around a white chevron, so it reads as "together, going up".

| File | Use |
|---|---|
| `../assets/logo.svg` | README, web pages, store listing source |
| `app/src/main/res/drawable/ic_launcher_foreground.xml` | Adaptive launcher icon (on black) |
| `app/src/main/res/drawable/ic_launcher_monochrome.xml` | Themed (monochrome) icon |
| `core/ui/src/main/res/drawable/bandwagon_logo.xml` | In-app mark |

Colours follow the palette in `AGENTS.md`. The other options are kept for reference.
